# 📝DailyNotes

<p align="center">
  <i>A little progress every day.</i>
</p>

A stationery-inspired productivity planner designed to make everyday task management simple, organized, and enjoyable. Create tasks, set deadlines, track progress, and celebrate small wins through a cozy, distraction-free interface.

## ✨ Features

- **Task Management** — Create, edit, and delete tasks with ease.
- **Categories & Priorities** — Organize tasks by Work, Personal, Study, or Other, with priority levels.
- **Due Dates** — Keep track of deadlines and upcoming tasks.
- **Task Status** — Mark tasks as completed or pending.
- **Search & Filters** — Find tasks quickly and filter by All, Active, or Completed.
- **Drag & Drop** — Rearrange tasks according to your preference.
- **Productivity Tracker** — Monitor completed tasks and daily progress.
- **Data Persistence** — Save tasks locally using LocalStorage.
- **Responsive UI** — Designed for a seamless experience across devices.

## 🎨 Design

Inspired by personal journals and stationery, Daily Notes features warm neutrals, pastel accents, paper-like cards, hand-drawn illustrations, and subtle animations for a calm and delightful user experience.

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| HTML5 | Structure |
| CSS3 | Styling, layout & animations |
| JavaScript (ES6+) | Logic & interactivity |
| LocalStorage | Persistent task storage |
